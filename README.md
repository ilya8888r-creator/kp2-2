# TaskFlow

Навчальний PWA-застосунок для огляду завдань на Vue 3, Framework7 і Vite.

## Запуск

```sh
npm install
npm run dev
```

## Збірка

```sh
npm run build
npm run preview
```

Застосунок містить головну сторінку, перелік завдань і сторінку з інформацією
про проєкт. На сторінці завдань можна фільтрувати, створювати й редагувати
завдання; зміни зберігаються в реактивному стані до перезавантаження сторінки.
Нижня панель переходить між сторінками за маршрутами Framework7.
