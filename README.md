# TaskFlow

Навчальний PWA-застосунок для керування завданнями та проєктами на Vue 3,
Framework7, Pinia і Vite.

## Запуск

```sh
npm install
npm run dev
```

## Збірка

```sh
npm run build
npm run preview
```

Застосунок містить головну сторінку, перелік завдань і сторінку з інформацією
про проєкт. Pinia централізує завдання, фільтри, проєкти та статистику, тож
зміни синхронізуються між сторінками без перезавантаження. На сторінці завдань
можна створювати проєкти, додавати й редагувати завдання, а також фільтрувати,
сортувати та групово змінювати їхній статус.

Дані зберігаються в оперативному стані й повертаються до демонстраційних
значень після перезавантаження сторінки. Нижня панель переходить між сторінками
за маршрутами Framework7.
